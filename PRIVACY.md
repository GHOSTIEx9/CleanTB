# Privacy Policy for CleanTB

**Effective Date:** October 31, 2026  
**Last Updated:** October 31, 2026

CleanTB ("the Application", "we", "us", or "our") is designed with a strict privacy-first philosophy. We believe that system desktop utilities should be lightweight, transparent, and completely respect user privacy.

This Privacy Policy explains our practices regarding data collection and usage when you install and use CleanTB.

---

### 1. Zero Personal Data Collection
CleanTB **does not collect, transmit, store, or sell any personal data or personally identifiable information (PII)**. 

When you use the Application:
- No names, email addresses, IP addresses, or device identifiers are collected.
- No taskbar activity, open application history, or typing input is monitored or logged.
- No network requests are made. CleanTB operates entirely offline.

---

### 2. Telemetry and Analytics
CleanTB contains **no analytics software, telemetry tracking, advertising frameworks, or crash-reporting beacons**. The Application does not communicate with external servers, third-party services, or APIs at any time.

---

### 3. Local Settings and Configuration
CleanTB stores your user preferences (such as your chosen taskbar visual preset, border visibility, and startup preferences) **strictly on your local machine** using local configuration files (`config.json`) and standard Windows APIs / user registry paths (`HKEY_CURRENT_USER`). 

- This configuration data never leaves your device.
- Uninstalling the application or deleting the application folder removes this configuration.

---

### 4. Permissions and Windows APIs
CleanTB interacts locally with standard Windows Shell and Desktop Window Manager (DWM) APIs solely to render taskbar effects (such as Acrylic, Blur, and Transparency) and listen for explorer restarts. It does not inspect window titles, file contents, or personal user data.

---

### 5. Third-Party Disclosures
Because CleanTB does not collect or transmit any information, **no user data is ever shared with, sold to, or processed by third parties**.

---

### 6. Children's Privacy
CleanTB does not knowingly collect or solicit any personal information from children or anyone else, complying with COPPA, GDPR, and Microsoft Store policies.

---

### 7. Changes to This Policy
If we update CleanTB in the future, any revisions to this Privacy Policy will be posted alongside the Application updates with an updated revision date.

---
